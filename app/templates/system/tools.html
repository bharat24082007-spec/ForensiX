{# Architecture Safeguards Banner #}

Subprocess Security & Forensic Safeguards

No Shell Execution Hard ban on shell=True. All commands are executed with structured parameter arrays directly through the OS kernel.
Dual Hash Verification Decrypted working copies are hashed with SHA-256 before and after tool runs to prove original evidence files are never modified.
Ephemeral Working Wiping Decrypted files in data/work/<job_id>/ are overwritten with zeroes and unlinked in a mandatory finally block.
Timeout & Output Caps Execution timeouts (default 30s) and stdout output caps (10MB) prevent hung processes and memory exhaustion attacks.
